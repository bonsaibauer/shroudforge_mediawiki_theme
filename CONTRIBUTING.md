# Contributing to ShroudForge

Thank you for helping improve the ShroudForge MediaWiki skin.

## Report an issue

Open a [bug report](https://github.com/bonsaibauer/shroudforge_wikijs_theme/issues/new?template=bug_report.yml) or a [feature request](https://github.com/bonsaibauer/shroudforge_wikijs_theme/issues/new?template=feature_request.yml). For code and documentation changes, open a pull request in this repository.

## Development

The skin targets MediaWiki 1.43 and newer. Install the Node dependencies with `npm ci`, then run the relevant checks listed in the root `AGENTS.md`. PHP checks require a MediaWiki checkout.

The manual and development release process is described in the root `README.md`.
