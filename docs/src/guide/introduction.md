# Introduction

![ShroudForge hammer mark](/img/shroudforge-mark.png)

ShroudForge is a responsive <a href="https://www.mediawiki.org">MediaWiki</a> skin styled with the dark navy, cyan accent, Inter typeface and hammer mark of [ShroudForge](https://shroudforge.net). Its interface is based on the open-source [Citizen skin](https://mwcitizen.skin/).

The skin keeps the features of its Citizen foundation while applying the ShroudForge visual design:

<LinkGrid>
    <LinkCard title="Responsive layout" href="../customization/theming#layout">
        The skin is responsive and is able to adapt to different screen sizes.
    </LinkCard>
    <LinkCard title="Command palette" href="../features/command-palette">
        The command palette offers a better search experience and support for custom commands.
    </LinkCard>
    <LinkCard title="Theme modes" href="../customization/theming#theme-modes">
        Users can choose the light or dark appearance.
    </LinkCard>
    <LinkCard title="Cohesive extension styles" href="../config/extensions">
        Supported extensions blend with the skin's interface.
    </LinkCard>
    <LinkCard title="Extensible preferences" href="../features/preferences">
        Let users personalize their experience, and let gadgets add their own options.
    </LinkCard>
    <LinkCard title="Collapsible sections" href="../config/#wgcitizenenablecollapsiblesections">
        Article sections on the wiki can be collapsed and expanded.
    </LinkCard>
    <LinkCard title="Progressive web app" href="../features/progressive-web-app">
        Users can add their wiki to the home screen for an app-like experience.
    </LinkCard>
</LinkGrid>

ShroudForge is open source under GPL-3.0-or-later. The repository includes credits for the Citizen contributors and the ShroudForge adaptation.
